# File Sorter

Desktop-приложение на Electron, которое автоматически раскладывает файлы в выбранной папке по категориям (Images, Documents, Music, Video, Archives, Other) в зависимости от расширения.

## Функции

- Выбор папки через системный диалог
- Сортировка файлов по категориям на основе расширения
- Лог выполненных операций прямо в интерфейсе
- Отмена последней сортировки (undo)
- Настраиваемые правила сортировки (расширение → категория) через встроенный редактор

## Запуск

```bash
npm install
npm start
```

## Тесты

```bash
npm test
```

Запускает набор тестов для `sorter.js` через встроенный `node:test`. Тесты работают с изолированными временными папками и не трогают реальные данные пользователя.

## Сборка дистрибутива

```bash
npm run dist
```

Собирает установщик через `electron-builder` (на macOS — `.dmg`). Результат появляется в папке `dist/`.

## Хранение данных

Правила сортировки (`rules.json`) и история последней сортировки для отмены (`history.json`) хранятся не в папке приложения, а в стандартной пользовательской директории данных (`app.getPath('userData')`), например:

- macOS: `~/Library/Application Support/file-sorter`

Это нужно, чтобы приложение могло сохранять настройки и после сборки в `.dmg`/`.exe` — папка с самим приложением доступна только для чтения. При первом запуске дефолтный `rules.json` из проекта копируется в эту директорию.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.js` | Главный процесс Electron: создаёт окно, инициализирует папку данных пользователя, обрабатывает IPC-запросы от интерфейса (выбор папки, запуск сортировки, отмена, чтение/сохранение правил) |
| `preload.js` | Безопасный мост между окном и главным процессом через `contextBridge` |
| `renderer.js` | Логика интерфейса: вкладки, обработка кликов, отображение лога и редактора правил |
| `sorter.js` | Основная логика сортировки файлов (работа с файловой системой); не зависит от Electron — пути к файлам правил и истории передаются параметрами |
| `sorter.test.js` | Тесты для `sorter.js` |
| `index.html` | Разметка интерфейса |
| `style.css` | Стили интерфейса |
| `rules.json` | Дефолтные правила сортировки (расширение → категория), копируются пользователю при первом запуске |
| `prototype.py` | Исходный Python-прототип логики сортировки, с которого начинался проект |

## Технологии

- [Electron](https://www.electronjs.org/)
- Node.js (`fs`, `path`)
- `node:test` для тестов
